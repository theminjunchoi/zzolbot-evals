# 24. 검정력 계산: 크기 축 실험을 설계 단계에서 기각했다

모델 크기 축 실험(0.5B / 1.5B / 3B에서 데이터 비율 곡선을 다시 긋기)에 하룻밤을 쓰려다
**먼저 계산했다. 그리고 지금 설계로는 판정이 불가능하다는 것이 나와 기각했다.**

이 레포 반복 실패 6번이 "계측 분해능을 확인하지 않고 개입 효과를 논함"이다. 이번에는
개입 전에 막았다.

## 1. 도구부터: `analysis/power.py`

검정력 계산을 이미 두 번 임시로 했다(리포트 09번의 906종, 19번의 110종). 매번 다시
짜면 정의가 어긋나므로 모듈로 만들었다.

- 짝지은 부트스트랩. **두 팔이 같은 시나리오 집합**에서 측정돼야 한다(아니면 거부한다)
- **알림 단위 군집 재추출이 기본이다.** 리포트 20번이 시나리오 단위의 문제를 지적했다
- MDE(80% 검정력, 양측 5%) = 2.80 x SE, 필요 표본은 효과의 제곱에 반비례

### 기존 수치와 대조

| | 리포트 20번 | 이번 실측 | |
|---|---|---|---|
| 알림 종수 / 시나리오 | 16 / 33 | **16 / 33** | 일치 |
| `AppErrorLogSpike` 군집 크기 | 7 | **7** | 일치 |
| 알림 단위 구간 폭 배수 | **1.7배** | **1.06배** | **불일치** |

**불일치는 도구 버그가 아니라 통계량이 다른 것이다.** 20번은 **한 팔의 AUC**를 쟀고
여기서는 **두 팔의 짝지은 차이**를 잰다. 짝을 지으면 시나리오 난이도가 상쇄돼 군집
상관이 거의 사라진다. 실측하면 짝지은 차이의 군집내 분산이 전체 분산의 47%다
(독립이면 100%에 가깝고, 강한 군집 상관이면 훨씬 작다).

**따라서 리포트 20번의 "216종"은 AUC형 분석에만 해당한다.** 짝지은 비교는 더 적게 든다.

## 2. n=33에서 잡을 수 있는 것

알림 단위 군집 부트스트랩, 10000회.

| 대조 | 관측 차이 | SE | MDE | 판정 |
|---|---|---|---|---|
| 학습 전 -> v4 (70:30) | **+0.2182** | 0.0445 | 0.1246 | **유의** |
| v4 -> v3 (59:41) | +0.0788 | 0.0486 | 0.1360 | 검출 불가 |
| v4 -> v2 (79:21) | +0.0121 | 0.0451 | 0.1263 | 검출 불가 |
| v6 -> v7 | -0.0455 | 0.0255 | 0.0715 | 검출 불가 |

**단순 차이 MDE는 0.115 안팎이다.**

상호작용(차이의 차이)은 부트스트랩으로 재니 SE가 단순 대비 1.10배, MDE 0.126이다.
**독립이면 sqrt(2)=1.41배일 텐데 1.10배로 그친다.** 같은 시나리오를 공유해 상관이
일부 상쇄되기 때문이고, 짝지은 설계의 이점이 상호작용에서도 남는다는 뜻이다.

## 3. 크기 축 실험이 겨냥한 효과는 이미 한계 아래다

1.5B 4bit의 비율 곡선을 보상으로 보면 이렇다.

| 학습 데이터 비율 | 보상 |
|---|---|
| v2 (79:21) | 0.8000 |
| v3 (59:41) | **0.8667** |
| v4 (70:30) | 0.7879 |

**곡선 전체 폭이 0.0788이다. MDE 0.115보다 작다.**

| 묻고 싶은 것 | 필요 표본 |
|---|---|
| 곡선 폭 자체를 잡기 | 약 **70종** |
| 크기에 따라 곡선 폭이 바뀌는가(효과 = 폭 전체라고 가정) | 약 **85종** |
| 크기에 따라 곡선 모양이 바뀌는가(효과 = 폭의 절반) | 약 **337종** |

**상호작용이 주효과 전체만큼 클 리는 없다.** 현실적인 값은 337종 이상이고,
계획한 116종으로도 리포트 20번의 216종으로도 안 된다.

**결론: "크기에 따라 최적 비율이 달라지는가"는 이 평가셋 규모에서 답할 수 없는 질문이다.**
9회 학습을 돌렸다면 무엇이 나오든 노이즈와 구별할 수 없었다.

## 4. 답할 수 있는 질문으로 바꾼다

| 질문 | 효과 | n=33 |
|---|---|---|
| 학습이 판별을 바꾸는가 (학습 전 -> 학습 후) | 0.218 | **가능** |
| 어느 비율이 최적인가 | 0.079 | 불가 |
| 크기에 따라 최적 비율이 달라지는가 | 상호작용 | 불가 (337종) |

**바꾼 질문: "학습 데이터 비율의 효과가 모델 크기를 바꿔도 재현되는가."**

크기마다 학습 전과 학습 후 두 팔만 재면 되고, 그 차이는 0.218이라 검출된다.
9회 학습이 6회로 줄고 **판정 가능한 실험이 된다.**

0.5B에서 재현되지 않으면 그쪽이 더 흥미롭다. "이 방법은 일정 크기 이상에서만 작동한다"가
되고, 그건 큰 효과라 지금 표본으로도 말할 수 있다.

## 5. 말할 수 있는 것과 없는 것

**말할 수 있다**
- **n=33에서 짝지은 보상 차이의 MDE는 0.115 안팎이다.** 알림 단위 군집 부트스트랩
- **비율 곡선의 전체 폭 0.0788은 이미 검출 한계 아래다.** 리포트 12번이 세 점으로
  그린 곡선은 **점들 사이의 차이가 유의하지 않다**
- 리포트 20번의 "알림 단위 1.7배"는 AUC에 대한 것이고, **짝지은 차이에서는 1.06배다**
- 상호작용 SE는 단순 대비 1.10배로, 짝지은 설계의 이점이 상호작용에서도 남는다

**말할 수 없다**
- **비율 곡선이 틀렸다** - 검출하지 못했을 뿐 효과가 없다는 뜻이 아니다.
  리포트 12번의 판정은 보상이 아니라 **인용 통과 건수**의 짝지은 검정(p=0.0391)이었고
  그건 다른 종점이다. 여기서 기각된 것은 **보상 종점에서의** 곡선 비교다
- **337종이면 충분하다** - 상호작용 효과 크기를 "곡선 폭의 절반"으로 가정한 값이다.
  실제 크기는 모른다
- **종점을 바꾸면 안 된다** - 인용이나 오탐만 따로 보면 신호 대 잡음이 나을 수 있다.
  재보지 않았다. 다음 후보다
