## 지표 정의 (문서마다 같은 뜻으로 쓴다)

같은 대상에 두 값이 보이면 정의가 다른 것이다. 둘 다 맞고 묻는 질문이 다르다.

| 지표 | 정의 | 예: 학습 전 모델 |
|---|---|---|
| **오탐 (접지 전)** | 음성 시나리오에서 `evidenceFound=true`로 답한 수. **모델의 판별력** | 15/18 |
| 오탐 (접지 후) | 그중 인용 검증까지 통과한 수. **봇의 실제 동작** | 3/18 |
| **인용 통과 (접지)** | 양성에서 인용이 로그의 **부분 문자열**인 수. 운영 코드와 같은 규칙 | 3/15 |
| 인용 통과 (엄격) | 인용이 로그 **한 줄 전체와 정확히 일치**하는 수. 보상 함수가 쓰는 규칙 | 1/15 |
| judge 총점 | LLM 채점자의 PASS 수. 33종 1시행 | 15/33 |
| 보상 | 형식 0.1 + 판정 0.5 + 인용 0.4의 평균. judge 미사용 | 0.570 |

**리포트 12번 이전은 접지 후 오탐을 썼고, 14번 이후는 접지 전을 쓴다.**
제약 디코딩을 붙이면 인용이 항상 정확해져 두 값이 같아지므로, 모델의 판별력을 재려면
접지 전이 맞다는 것이 [14번](14-보상함수와-제약디코딩.md)에서 드러났다.

## runs/

하네스가 직접 쓴 파일이다. 손으로 고치지 않는다.

- `*-endpoints.{md,json}` - 종점 측정(인용 통과, 오탐). judge 미사용
- `*.jsonl` - 시나리오별 시행 원본(질문, 답변, judge 점수)
- `judge-cal*` - judge 변별력 캘리브레이션
- `verdict-prob/*.json` - 팔별 판정 확률 P(evidenceFound=true). 시나리오 33종
- `*-raw.json`, `*.diff` - 자바 하네스 실행 원본과 프롬프트 변경분
- `21-torch-mps-*.log` - torch/MPS 속도 게이트 원본. 오염된 첫 측정도 지우지 않고 남겼다
- `22-엔진대조-*.log`, `port2-*-reward.*` - MLX와 torch 대조 원본. 실패한 1차도 남겼다
