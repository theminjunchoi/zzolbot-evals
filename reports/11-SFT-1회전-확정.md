# SFT 1회전 확정 결과

> 이 문서가 SFT 1회전의 유효한 결과다. 이전 `09-1차-SFT-비교-무효.md`는
> 학습 데이터 70%가 잘린 상태의 측정이라 무효 처리했다(`10-학습데이터-잘림-회고.md` 참조).

- 모델: Qwen2.5-1.5B-Instruct-4bit, LoRA(마지막 16층)
- 학습: max_seq_length 3200(잘림 0건), batch 1, 400 iter, lr 1e-4, 시드 2개
- 데이터: 100 샘플(train 85 / valid 15), 교사 gemini-2.5-flash
- 평가: 골든셋 33종, production 프롬프트, judge specificity-aware
- 평가는 1시행. **분석기와 judge가 모두 temperature 0이라 시스템이 결정적이고, 33종 중 33종이
  5시행 결과가 완전히 일치함을 확인했다.** 반복은 검정력을 주지 않는다.

## 결과 요약

| 지표 | 베이스 | 학습 후 | 판정 |
|---|---|---|---|
| **인용 검증 통과 (표적)** | 3/15 | **11/15** | 개선 8 / 악화 0, **p = 0.0078** |
| 총점 | 47% | 58% | 개선 11 / 악화 8, p = 0.65 (유의하지 않음) |
| **오탐 (부작용)** | 17% | **44%** | 악화 |

## 1. 표적 행동은 가르쳤다 (확정)

Phase 1 진단은 "모델이 근거는 알아보는데 인용을 원문 그대로 복사하지 못해 코드가 강등한다"였다.
학습 데이터의 최우선 목표를 그 행동으로 잡았고, 결과가 나왔다.

| 조건 | 근거 주장 | 인용 통과 | 파싱 실패 |
|---|---|---|---|
| 베이스 | 13/15 | **3/15** | 0 |
| 학습 후 시드1 | 14/15 | **11/15** | 0 |
| 학습 후 시드2 | 14/15 | **11/15** | 0 |

- **짝지은 검정 p = 0.0078** (개선 8, 악화 0). 베이스가 통과하던 3종을 그대로 유지하면서
  8종을 추가로 통과시켰다. 기존 능력을 훼손하지 않았다는 뜻이다.
- **시드 두 개가 통과 개수, 개선/악화 구성, 주장 횟수까지 완전히 일치**한다.
  15종 중 11종에서 같은 판정을 냈다.
- 근거 주장 횟수는 13 → 14로 거의 변하지 않았는데 통과만 늘었다. 판단력이 아니라
  **겨냥한 출력 행동만 바뀌었다**는 구조적 증거다.

이 결과는 44종 확대 없이 확정됐다. 앞서 44종이 필요하다고 계산한 것은 그때 효과 크기
(개선 5 / 악화 1) 기준이었고, 실제 효과(개선 8 / 악화 0)가 훨씬 커서 15종으로 충분해졌다.
**계산을 먼저 한 덕에 두 시간짜리 확대 작업이 불필요해졌다.**

## 2. 예측한 부작용이 나타났다

Phase 1에서 미리 등록한 위험이 두 번 확인됐다.

> 학습 데이터의 판정 분포가 근거 있음 79 / 없음 21로 치우쳐 있어, 반대 방향으로 무너질
> 위험이 있다. Phase 4에서 유형 D(오탐)를 별도로 봐야 한다.

| | 오탐 비율 |
|---|---|
| 베이스 | 17% |
| v1 (데이터 잘림 상태) | 28% |
| **v2 (잘림 없음)** | **44%** |

데이터가 온전해지면서 학습이 더 강하게 걸렸고, 부작용도 함께 커졌다.
총점의 악화 8건 중 **7건이 "근거 없음"이 정답인 시나리오**다.

## 3. 총점은 변하지 않았다

47%에서 58%로 올랐지만 짝지은 검정은 개선 11 / 악화 8, p = 0.65다. 유의하지 않다.
표적 개선과 부작용이 상쇄되기 때문이고, 이는 **총점이 이 실험에 맞는 종점이 아니라는 뜻**이다.
검정력 계산상 총점 차이를 확정하려면 906종이 필요하다.

## 말할 수 있는 것과 없는 것

- **말할 수 있다**: 겨냥한 행동(로그 원문 그대로 인용)을 가르쳤고, 시드 재현성과 통계적
  유의성(p < 0.01)을 확인했다. 기존에 맞히던 것을 훼손하지 않았다.
- **말할 수 있다**: 데이터 판정 분포가 치우쳐 오탐이 늘어난다는 것을 사전에 예측했고 실측했다.
- **말할 수 없다**: 전체 성능이 좋아졌다.

## 2회전으로 넘어가는 근거

부작용의 원인 가설(데이터 79 대 21)과 처방(균형 조정)이 모두 특정돼 있고, 성공 조건도
사전에 정할 수 있다. 다음 실험의 등록된 기준은 이렇다.

| 판정 | 조건 |
|---|---|
| 성공 | 인용 통과 10/15 이상 유지 **AND** 오탐 25% 이하 |
| 부분 성공 | 오탐은 내려갔으나 인용도 함께 하락 (트레이드오프 곡선 확인) |
| 실패 | 오탐 그대로 → 데이터 비율 가설 기각, 다른 원인 탐색 |
