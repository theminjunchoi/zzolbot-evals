# zzolbot-evals

> 운영 모니터링 봇 [zzolbot](https://zzol.site)의 LLM 알림 분석 품질을 측정하고 개선하는 평가 프로젝트

zzolbot은 Alertmanager 알림을 받아 로그를 근거로 LLM이 근본 원인을 분석하는 운영 봇이다. 이 프로젝트는 실제 프로덕션 인시던트를 골든 시나리오로 박제해 그 분석 품질을 정량 평가하고, 오답 유형 분석에서 찾은 약점을 겨냥해 개선한 뒤 전후 성능을 비교하는 사이클을 다룬다.

- **골든셋 평가**: 실제 시스템의 로그 포맷, 알림 룰과 정합하는 시나리오 기반 회귀 평가
- **LLM-as-judge 채점**: rubric 기반 자동 채점과 근거 접지(grounding) 검증
- **오답노트**: 실패 사례를 유형화하고 대조군 실험으로 약점의 원인을 입증
- **개선 사이클**: 프롬프트 개선과 소형 모델 학습(SFT, RLVR)의 전후 성능 비교
